# colab-utils
Collection of my gooogle colab notebooks (python sccripts) for various utility tasks.

## Uploaded from Colab → GitHub
In Colab: **File → Save a copy in GitHub** → choose this repo.
That's cuz of this repo was created and how most notebooks here were added.


## Why "U-" prefix?
Originally all notebooks were named `Untitled*.ipynb` by Colab default.
To keep things organized I started prefixing them with `U-` 
(can mean **Utility** or **University**).

## How to use
1. Open any `.ipynb` file in Google Colab
2. Run cells in order (or all together)
3. Adjust parameters as needed
